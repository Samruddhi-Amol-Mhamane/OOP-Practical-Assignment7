## 🎯 Aim / Problem Statement
To develop and implement a C++ program to demonstrate runtime polymorphism using virtual functions and base class pointers. The program shows how a single function call behaves differently based on the object it is referencing at runtime.

---

## 💡 Concepts Covered
* **Runtime Polymorphism:** Achieving dynamic method dispatch at runtime.
* **Virtual Functions:** Using the `virtual` keyword in a base class to allow overriding in derived classes.
* **Base Class Pointers:** Managing objects of derived classes using pointers of the base class type.
